# Historical course outputs

All eleven PNGs were extracted from embedded outputs in the final course notebook. No plots or models were rerun in Stage 1. `figure_manifest.json` records their source cell/output and SHA-256 hash. `notebook_text_outputs.json` preserves the notebook's saved printed results. `saved_model_metrics.json` separates the exact saved ROC-AUC from rounded classification metrics.

These outputs inherit the course analysis limitations. In particular, the decade plot denominator is unique players, the team plots use 2015–2022 despite titles saying 2000–2022, and the original model uses full-season predictors with a random split. Do not use these figures or metrics as verified portfolio evaluation results.
